## 規則與時序

每日Q = 三大法人多空交易口數淨額總和 ÷ 三大法人多方與空方交易口數總和。分子是成交淨流量，並非未平倉淨額；分母只涵蓋三大法人，不是全市場成交量。

當日Q與前19日Q算術平均大於0，且當日近月收盤大於含當日在內20日收盤均價，隔交易日開盤持有一口多單；任一條件消退，隔日開盤全部退出。相等視為空手。持有期間跨日留倉，不做每日收盤退出、不做空、不加碼、不設停損。最後樣本日收盤清倉為帳戶結算例外。

資料包含日盤實際月契約，沒有使用連續契約價差當作損益。策略價格均線使用未回溯調整的日盤近月收盤，可能受到換月基差影響。訊號整體向後移一個交易日，逐日底稿附有前一日訊號與全部特徵。

正式比較期間為2018-08-31至2026-10-05。起始日沿用先前18個候選規則比較時的共同期間（其中最長需60日暖機）；本策略本身只需20日暖機，Q20自2018-07-03起即可計算，但該段未納入正式期間。

三大法人資料由期交所於交易日收盤後公布，本回測保守採T+1日日盤08:45開盤為最早執行時點，不假設T日資料可於T日夜盤成交。

## 基準、轉倉與成本

Buy-and-Hold在首日開盤買一口，持有至樣本最後收盤。雙方都在到期前一交易日日盤13:45，用舊月收盤賣出、新月收盤買進；此安排避免到期日舊月13:30與新月13:45不同時點成交。策略只在當時有持倉時換倉。

每口每點200元。每次成交單邊手續費50元、滑價2點；買進成交價為報價+2、賣出為報價−2。期交稅按滑價後成交價×200×0.00002逐邊計算，未作整數捨入。轉倉兩腿都收費。價格損益以同一實際契約計算，滑價另扣一次，換月價差不直接算獲利或損失，也不另扣第二次。

策略147次完整方向交易、37次轉倉、184個實際契約段、368次成交；基準97次轉倉、98個契約段、196次成交。基準每次交易的統計單位是月契約段，策略是完整方向交易，勝率與PF的持有期間不同。

固定一口Buy-and-Hold仍是主要、可執行的比較，但它有1,968個交易日市場曝險，策略只有658個日末持倉日，所以「同一口」不等於「同風險」。它的MDD較高，部分原因只是持有市場的時間更長。

正式報告另將固定一口基準的逐日毛損益與交易成本同比例縮放至約0.293口，使完整樣本年化波動與策略相同。這項事後波動配平只用於同風險尺度的表格診斷；小數口TX不能直接交易，亦非樣本外驗證。

共同起始資金不代表歷史保證金要求；本回測不模擬逐日保證金及追繳。閒置資金利息與Sharpe無風險利率為0。日報酬=當日淨損益/前一日權益，Sharpe採252日年化與樣本標準差；CAGR按含起訖日的曆日數/365.25。最大回撤金額與比例各自取最大值，可能出現在不同日期。日OHLC回測不能觀察完整盤中最差損失或限價成交可得性。

## 資料與研究限制

價格整理資料涵蓋2016-10-05至2026-10-05、2,438個交易日、14,202列實際月契約、126個契約；所有正式回測所用近月OHLC完整。原始179列OHLC缺值保留於稽核，多為無成交遠月，不以零值或假價格填補。

法人資料只有2018-06-05至2026-10-05、2,030日、6,090列三大法人資料，並非十年法人資料；2016-10-05至2018-06-04有408個價格交易日缺法人資料。早期官方交易金額淨額缺漏保留空白，但本策略使用完整的交易口數欄位，未使用缺漏金額欄位。

法人來源6,090筆比對有2筆差異，均在2026-07-06；Q20在20天有變化，但目前沒有不同進出場訊號。歷史初次發布快照與後續修訂無法完整驗證，不能將本資料稱為全期已核實的point-in-time資料。

以換月前一交易日兩契約收盤重疊價差調整價格訊號，14天進出條件不同，診斷路徑淨利3,028,972.772元、Sharpe 1.245；正式策略為3,277,536.576元、Sharpe 1.367。成交與損益都沿用真實契約。見 `output/roll_gap_signal_audit.csv` 與摘要JSON。

法人條件對價格單獨策略的增量請見 `output/flow_incremental_attribution.csv`；按執行日目標狀態分類，開盤平倉前的隔夜損益可能出現在當日空手分類。價格單獨策略以全樣本事後波動配平至0.437口TX-equivalent後，淨利約2,108,818元、Sharpe 1.020；小數口不可直接交易。

特殊期間（2018Q4、2020年2～3月、2021年5月、2022年全年、2024年8月、2025年4月，以及2026年3月、6月兩個由資料辨識的單日跳空）的訊號狀態見 `output/event_windows.csv`：策略在八個視窗的最深開盤跳空日均為空手，這是雙條件在下跌初期即退出的結果而非預測；代價是跳空後重新進場前近月多已回升。事件視窗為事後描述，未用於調整規則。

穩健性與統計推論（全部為事後診斷）：36組參數格點中86%的Sharpe高於1、全部淨利為正，20/20排第8；只用2018–2022挑選會選到60/20。延遲一日執行、提前兩日換倉、成本×1.5／×2、換月價差調整訊號、替代法人來源七個情境的Sharpe介於1.245至1.437。在收盤>MA20的訊號日中，Q20>0相對Q20≤0的次日平均報酬差約+11.8 bp（Welch t≈1.9）；Q20五分位的次日報酬並非單調。20日區塊bootstrap的策略Sharpe 95%區間約[0.63, 2.09]，與固定一口基準[0.46, 1.91]及價格單獨策略[0.41, 1.88]重疊，統計上不能宣稱策略Sharpe高於基準。以上數字由 `output/robustness_summary.json` 與對應CSV重現。

本策略從先前18個候選中挑出；本報告是全樣本探索，沒有獨立未接觸的樣本外驗證。成本敏感度、拆開兩項條件、參數格點、bootstrap與時間分組都只是事後診斷，信賴區間亦未校正候選挑選。過去績效不能當作已驗證的未來優勢；需固定規則後使用全新期間檢驗。

## 重現

在解壓後本資料夾執行（Python 3.12已驗證）：

```bash
python -m pip install -r requirements.txt
python validate_inputs.py
python backtest.py
python make_report.py
python ci_verify.py
```

`prospective_protocol.json` 已先固定2026-10-05之後資料的觀察門檻與評估標準；`prospective_gate.py` 對未來逐日交易帳本驗證日期、訊號先於交易、權益與報酬對帳，未滿252日只回報 pending。帳本須由另外審查的前瞻重播流程提供，單靠檢核不能證明訊號來源時點。必須蒐集至少252個完全未用於選擇規則的新交易日與當時來源快照，才能宣稱完成真正的未來樣本驗證；目前尚無此結果。

`regression_baseline.json` 集中記錄目前固定資料的期間、參數、輸入 SHA-256、關鍵指標及容差，`backtest.py` 與 `ci_verify.py` 共用。修改期間、資料或參數時，先檢查損益與訊號對帳及資料來源，再審查新結果並增加 `baseline_revision`、更新參考值及雜湊；不應因回歸失敗直接把新數值複製進基準。mismatch 會列出期望值與實際值。再次跑backtest會重建基礎工作簿，之後跑make_report才會補回圖表及中文字典。

`output/validation.json`記錄一口參考資金、參數、輸入SHA-256及訊號／帳務驗證；`output/final_verification.json`由 `backtest.py` 每次重建，記錄策略與固定一口基準的關鍵重現值。每日損益、契約段損益、成交成本已對帳；成交報價另核對實際契約開盤或收盤。XLSX與DOCX ZIP容器、PDF/PNG簽章及必要輸出可由 `python ci_verify.py` 再驗證。

GitHub Actions 的 `.github/workflows/regression.yml` 使用Python 3.12，在push、pull request或手動觸發時依序安裝固定版本依賴、執行 `backtest.py`、`make_report.py` 與 `ci_verify.py`。CI只在runner工作目錄重建產物，不會自動commit或push正式輸出。

中文字型為Noto Sans TC，附`FONT_LICENSE.txt`。全部資料可獨立離線重跑；下載來源與雜湊見稽核資料。本包保留重現所需原始列與來源紀錄，完整年度官方壓縮檔在先前的價格資料產出中。
